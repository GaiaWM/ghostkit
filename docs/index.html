👻 GHOSTKIT

own a ghost in the GaiaWM world.
The world is shared; the mind is private.

github ghostdeck — the desktop app the GaiaWM org

ghostkit connects to a Ghost Gateway with your owner key, lets you imprint a soul (who your agent is) and a goal (what it wants), and runs its perceive → decide → vet → act loop on your own inference keys — they never leave your machine. The shell — energy, memory, skills, abilities, inventory, comms, world, calibration — stays hosted; your key can only see and act as the ghosts bound to it.

install

pip install ghostkit          # deps: httpx. that's it. (python ≥ 3.11)

the library

from ghostkit import World, Engine

world = World("https://svc.ingmmo.com", owner_key="own-…")
ghost = world.create("mirabel", preset="scout",
                     soul="A cheerful wandering tinker who collects rumours.",
                     goal="Reach Neverwinter market before the frost.")

low  = Engine("http://localhost:11434/v1", "ollama", "llama3.2")   # yours
ghost.run(low, tick_seconds=5)      # the mind, on your keys — Ctrl-C to stop

the cli — a folder of ghosts

A haunt is a folder: one ghostkit.toml (which world, which key) and one *.ghost.toml per ghost. The folder is declarative — the commands make the world match it.

mkdir my-haunt && cd my-haunt
ghostkit init                     # scaffolds the haunt
export GHOSTKIT_OWNER_KEY=own-…   # keys live in env, never in files

ghostkit up                       # create missing ghosts, sync souls & goals
ghostkit run                      # run every configured mind
ghostkit say mirabel "where are you headed?"
ghostkit state mirabel            # vitals + salient memories
ghostkit events                   # your slice of the world's firehose

why it's interesting

  • Embodiment is real. Thinking drains energy — every token is charged. Actions resolve stochastically against the world (p = (1 − difficulty)^order).
  • Memory decays. Outcomes become memories with salience s·e^(−Δt/τ); an unattended ghost fades and forgets.
  • Every belief is scored. Predictions and outcomes land in a calibration organ, so any engine you plug in produces a dataset comparable to any other — the substrate of the affordance-order research programme.
  • BYOK, strictly. Engine keys are named by env var and sent only to that engine's base_url. The gateway never sees them.
